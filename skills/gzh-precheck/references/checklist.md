# 发布前检查清单

> 检查维度参考 ZJU-REAL/Easel 的 `skill-publish-checklist`、`skill-quality-gate/references/general-rules.md`、`skill-risk-scanner`（Apache-2.0），以及 wewrite 的 `wewrite-review`“逐项对到来源”的做法（MIT）。已按本项目“只做手动发布、每条事实带出处”的规则重写。

## 脚本项（`scripts/check_sources.py`）

| 类别 | 检查 | 级别 |
|---|---|---|
| 元数据 | 标题存在且 ≤32 字；摘要 ≤120 字；作者 ≤16 字 | 错误 |
| 元数据 | 没有摘要 | 警告 |
| 出处 | 含数字、日期、引语或归因词（发布、宣布、表示、据……）的句子，所在段落没有链接或脚注 | 错误 |
| 出处 | 脚注引用没有定义，或定义里没有链接 | 错误 |
| 出处 | 出处是搜索结果页或占位链接（example.com、.invalid 等） | 错误 |
| 出处 | `--online` 时链接打不开 | 警告 |
| 限定词 | 与初稿相比，“可能 / 据称 / 计划 / 预计 / 尚未 / 约 / 超过 / 至少……”的数量减少 | 错误 |
| 限定词 | “必然 / 将会 / 证实 / 已经……”比初稿多 | 警告 |
| 数字 | 终稿出现初稿没有的数字 | 错误 |
| 数字 | 标题里的数字没有出现在正文 | 错误 |
| 数字 | 初稿的数字在终稿消失 | 警告 |
| 绝对化 | 正文出现“最 / 第一 / 唯一 / 100% / 绝对 / 保证 / 史上 / 全网……” | 警告 |
| 绝对化 | 标题出现上述词 | 错误 |
| 对照表 | 标为“已核实”的事实没有出处链接 | 错误 |
| 对照表 | “待核实 / 不支持”的论点 | 警告（人工确认没进正文） |
| HTML | `gzh-format` 合规检查的错误 / 警告 | 同原级别 |
| 封面 | `gzh-cover` 自检未通过 | 错误 |

公众号的标题、作者、摘要和正文长度上限来自官方文档《新增草稿》（developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_add.html，2026-10 查阅：标题不超过 32 个字，作者不超过 16 个字，摘要不超过 120 个字，正文少于 2 万字符）。后台编辑器的限制可能不同，以发布时后台提示为准。

## 人工项

### 事实与出处
- [ ] 每个出处都打开过，页面内容确实支持正文的说法
- [ ] 数字、日期、主语、单位与来源一致
- [ ] 来源的限定说法（计划、预计、据称、可能）在正文中保留
- [ ] 引语与原文一字不差，译文注明“译文”
- [ ] 时效性事实写明了时间（“截至 X 月”）

### 原创与授权
- [ ] 没有大段复制来源原文；引用只取支撑论点所需的最短部分
- [ ] 图片为自制、官方公开素材（注明来源）或已获授权
- [ ] 没有使用他人商标、logo、人物肖像做封面主体

### 表达
- [ ] 没有编造的个人经历、朋友同事、对话、采访
- [ ] 观点和推断能被读者看出是观点和推断
- [ ] 标题与正文一致，没有标题党，没有正文里不存在的数字或承诺
- [ ] 医疗、投资、法律相关内容没有给出确定性建议

### 发布
- [ ] 发布方式为手动，发布包里没有任何账号凭据
- [ ] `publish.md` 的标题、摘要与终稿一致
