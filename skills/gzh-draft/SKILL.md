# gzh-draft：写公众号初稿

先定义文章、再列论点和证据、最后才写正文。输出初稿 `02-draft.md` 和对照表 `02-claims.md`。初稿不是成稿，之后还要经过 `zh-humanize` 和 `gzh-precheck`。

## 输入

- `01-topic-card.md` 里结论为“做”的那个选题。
- 选题卡里列出的原始资料链接，以及写作中补查到的资料。
- 账号口吻（可选）：第一人称“我”还是编辑部口吻，有没有参考范文。没有就用克制、直接的第一人称判断口吻，不编个人经历。

## 步骤

### 1. 写任务书（不写正文）

在 `02-claims.md` 顶部写清楚：

- 目标读者、阅读情境、他们真正要解决的问题；
- 读完能复述的一个结论，以及能采取的行动或判断方法；
- 全文核心判断、它比常见说法多出来的部分、成立的边界、最强的反方；
- 一个可被反对的判断，以及它在什么条件下不成立；
- 个人材料：只有人在本次任务里明确提供的经历、观察、原话才算。没有就写“无”。

### 2. 列论点–证据–出处对照表

围绕核心判断，列出 3–6 个文章必须证明的论点。每个论点一行，格式见 `references/claims-table.md`：

- 类型分为 `事实 / 推断 / 观点 / 用户材料`。
- **事实**必须有能直接支持它的出处链接，并且你已经打开原页面核对过。只看过搜索摘要的，状态写 `待核实`，不能进入正文。
- **推断**要写明依据哪几条事实，正文里要让读者看出这是推断（“由此看”“我的判断是”）。
- **观点**不伪装成共识，不写“业内普遍认为”。
- 原文是“计划 / 预计 / 据称 / 可能 / 约 / 超过”的，对照表里原样记录，正文同样保留。

### 3. 搭结构

不套固定骨架。“发生了什么 → 为什么值得关注 → 我们的判断 → 边界与反方 → 读者可以怎么做”这类每篇都一样的五段式，本身就是一眼能认出的机器结构。先回答两个问题再排段落：读者最先想知道什么？读到哪里会开始怀疑？然后按 `templates/article.md` 的提示排段落，每一节标注它服务哪个论点（写在 HTML 注释里，`gzh-format` 会去掉）。

- **从读者的问题或一个反常事实开头。** 开头要么是目标读者正在面对的一个具体问题，要么是一个和常识相反、有出处的事实。不从背景介绍或“是什么”讲起。
- **至少一个可被反对的判断。** 全文要有一个明确的判断，讲理的读者可能不同意它；同时写明它在什么条件下不成立（“如果你的场景是……，这个判断就不适用”）。这个判断在对照表里记为 `推断` 或 `观点`，不能伪装成事实。
- **至少一节在做对比或核实。** 拿原始资料验证一个流行说法，或者把两种做法、两个来源放在一起对照，指出哪里对不上。
- **按内容分配篇幅。** 最有新意的那一节写长，交代背景的地方一两句带过；各节长短不一是正常的。
- **小标题写这一节回答的具体问题**，不用“背景”“影响”“总结”这类每篇都能用的通用词。
- **对比型**（两种做法 → 关键差异 → 适用条件 → 怎么选）和**清单型**（每一项都有独立信息时才用，不为凑数补项）仍然可用，但同样要满足上面几条。

### 4. 写正文

- 篇幅一般 1200–2500 字，选题卡另有建议时按建议。
- 开头两三句内进入读者的具体问题，或者一个和常识相反且有出处的事实（有出处的具体数字也可以）。不用“随着……的发展”铺垫，不先下定义，不编造亲身经历、朋友同事、对话场景。
- 每条具体数字、日期、引语、产品能力、研究结论，在同一段内给出处：Markdown 链接或脚注 `[^n]`。
- 引语必须一字不差地来自来源，翻译的要注明“译文”。
- 写出最强反方和适用边界，不只报喜；那个可被反对的判断，要在正文里写明它不成立的条件。
- 结尾交付结论、行动或一个还没解决的问题，不复述前文论点，不用“让我们拭目以待”。

### 5. 自查后交出

- 正文里每个事实句都能在对照表里找到对应行，状态为 `已核实`。
- 对照表里 `待核实` 和 `不支持` 的行，正文中都没有出现。
- 没有任何第一人称经历是编出来的。
- 结构自查：每段首句连读不像一份工整的摘要；至少一节在做对比或核实；有一个写明不成立条件的判断；结尾没有复述论点。
- 标题给出 1 个主标题和 2 个备选，主标题不超过 32 个字，不虚构数字，不做承诺式标题党。
- 写一段不超过 120 字的摘要，放在 front matter 的 `digest`。

## 规则

- 不用模型记忆充当出处。资料查不到，就缩小论点或删掉这一段。
- 不改变来源的确定程度：来源说“可能”，正文不能写“将会”。
- 不复制来源的大段原文；引用控制在支撑论点所需的最短长度，并注明出处。
- 范文只能参考节奏和结构，不能借用其中的经历、观点和句子。
